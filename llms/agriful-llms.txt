# Agriful

> Agriful (Agriful Software Inc.) is a cloud-based ERP for the fresh produce
> industry. It runs sales and purchase order entry, live inventory control,
> lot-level traceability for FSMA and PTI compliance, produce-specific AR/AP
> accounting and grower settlements, and customizable reporting and dashboards
> for produce brokers, marketers, packer-shippers, wholesalers and distributors.
> The product is delivered entirely in the browser at app.agrifulsoftware.com,
> with nothing to install. Agriful was founded in 2022 by Patrick Crowley (CEO)
> and Deep Randhawa (CTO), is incorporated as Agriful Software Inc., and is
> backed by Fractal Software and Reservoir Ventures.

## Status

- No public API. Probed 2026-09-12: Agriful publishes no developer portal, API
  reference, OpenAPI or Swagger description, GraphQL SDL, AsyncAPI, JSON Schema,
  SDK, CLI, Postman collection, webhook catalog or sandbox. Probes of
  /openapi.json, /openapi.yaml, /swagger.json, /v1/openapi.json, /api-docs,
  /docs, /redoc, /api/schema and /graphql were run against the marketing host
  (www.agrifulsoftware.com), the application host (app.agrifulsoftware.com) and
  the API host (api.agrifulsoftware.com). docs.agrifulsoftware.com and
  developers.agrifulsoftware.com do not resolve in DNS.
- No /.well-known/ documents. security.txt, openid-configuration,
  oauth-authorization-server, oauth-protected-resource, api-catalog and
  ai-plugin.json all 404 on agrifulsoftware.com, www.agrifulsoftware.com and
  api.agrifulsoftware.com. app.agrifulsoftware.com answers 200 for every
  /.well-known/ path with its single-page-app HTML shell, which is a catch-all
  route and not a document.
- No agent card. Neither /.well-known/agent-card.json nor the legacy
  /.well-known/agent.json is served; the 200s on app.agrifulsoftware.com are the
  same SPA shell and fail every A2A AgentCard shape check.
- No /llms.txt is published by Agriful. This file is generated by API Evangelist
  from the public record, not served by the company.
- No MCP server, hosted or stdio. No mention of the Model Context Protocol exists
  on any Agriful surface.
- No client libraries. Nothing named agriful exists on npm, PyPI, RubyGems,
  Packagist, crates.io, NuGet or the Go module proxy, and the
  github.com/Agriful-Software organization has zero public repositories.
- There IS one live machine surface, and it is not for you: a RedwoodJS GraphQL
  endpoint at https://api.agrifulsoftware.com/graphql that backs the Agriful web
  application. It answers anonymous POSTs, but introspection is disabled in
  production, no schema, reference or authentication documentation exists for it
  anywhere, and the Terms of Service grant access only to Authorized Users under
  an executed Order Form. It is the app's private backend, not a developer API.
  Do not treat it as an integration point.
- No published pricing. Every conversion path is a "Get a demo" contact form;
  /pricing returns the site 404 and fees are set per customer in an Order Form.
- No published rate limits, status page, changelog, versioning policy,
  deprecation policy, vulnerability disclosure program or trust center.

## If you need to integrate

There is no self-service path. Contact info@agrifulsoftware.com or use the demo
form; any data exchange is negotiated under an Order Form. Do not attempt to call
api.agrifulsoftware.com/graphql — it is undocumented, unversioned, access is
restricted to Authorized Users by the Terms of Service, and its shape can change
without notice because it is an internal application backend.
